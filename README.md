# AI 연수원 — 해보면서 배우는 AI

AI를 "ChatGPT에 질문하는 것" 정도로만 아는 사무직이 **직접 조작하면서** AI가 실제로 어떻게 일하는지,
도구들이 서로 뭐가 다른지 이해하게 만드는 웹 게임이다. 필수 코스 10판이면 약 17분이다.

읽는 자료가 아니다. 세팅하고, 실행 버튼을 누르고, 자기가 세팅한 대로 AI가 움직이는 걸 본 뒤
결재 도장으로 판정을 받는다.

- 설치 없음 · 로그인 없음 · **인터넷 연결도 API 키도 필요 없다**
- 외부 네트워크 요청 **0건** (사내망 차단 환경 대비)
- 한국어 · 모바일 우선 (360px)
- 진행도는 그 브라우저에만 저장된다. 수집·전송 없음

## 열어 보기

### 배포 주소로 열기 (사용자용)

링크를 받았다면 그대로 열면 된다. 설치할 것도 설정할 것도 없다.

### 내 컴퓨터에서 확인하기 (개발용)

`index.html` 을 **더블클릭하면 열리지 않는다.** 화면 조각이 ES 모듈로 나뉘어 있는데,
`file://` 로 연 페이지는 브라우저 보안 정책(CORS)이 모듈 불러오기를 막는다.
이 경우 화면에 "파일을 직접 열면 실행되지 않습니다" 안내가 뜬다.

Windows에서는 **`start.cmd` 를 더블클릭**한다. 작은 웹 서버를 띄우고 브라우저를 자동으로 연다.
Python 이 없으면 `py`, 그것도 없으면 `npx serve` 순으로 찾는다. 끝낼 때는 검은 창을 닫는다.

직접 명령으로 띄우려면:

```bash
python -m http.server 8765
# 그 다음 http://localhost:8765 접속
```

## GitHub Pages 배포

빌드 단계가 없다. 저장소를 그대로 올리면 그게 배포본이다.

1. GitHub에 저장소를 만들고 이 폴더를 push한다 (`.nojekyll` 포함 — 빠지면 안 된다)
2. 저장소 **Settings → Pages**
3. **Source**: `Deploy from a branch`
4. **Branch**: `main` / **폴더**: `/ (root)` → Save
5. 1~2분 뒤 아래 주소로 열린다

```
https://<계정이름>.github.io/<저장소이름>/
```

이 주소를 사내 메신저로 공유하면 모바일에서 바로 열린다.

- **`.nojekyll` 이 필요한 이유**: 없으면 GitHub Pages가 Jekyll로 한 번 가공하는데,
  이때 `_` 로 시작하는 파일과 폴더를 빼 버린다. 정적 파일을 그대로 내보내려면 이 빈 파일이 있어야 한다.
- **모든 경로는 상대경로여야 한다**: Pages 주소는 `.../<저장소이름>/` 아래에 붙는다.
  절대경로(`/assets/`)는 도메인 루트를 가리켜서 404가 난다. 이 저장소는 전부 `./assets/`, `./src/` 로 쓰여 있고
  라우팅도 해시(`#/game/...`)라서 저장소 이름이 무엇이든 그대로 동작한다.

## 폴더 구조

```
/
├── index.html            시작점. file:// 안내 화면도 여기 들어 있다
├── start.cmd             로컬 확인용 (배포에는 불필요)
├── .nojekyll             GitHub Pages 필수 (빈 파일)
├── package.json          anime.js 를 assets/vendor/ 로 복사할 때만 쓴다
├── GAME_SPEC.md          설계 명세 — 구조를 바꾸기 전에 여기부터
├── TERMS.md              용어 원본 (출처 포함) — 콘텐츠 수정은 여기서 먼저
├── PROGRESS.md           지금 되는 것 / 알려진 함정 / 다음 할 일
├── CLAUDE.md             작업 규칙
├── AI-GAME-PROMPT.md     최초 요구사항 원문
├── assets/
│   ├── tokens.css        색·글꼴·간격 — 값은 전부 여기에만
│   ├── styles.css        공통 셸 스타일
│   ├── game.css          게임 무대 스타일
│   ├── codex.css         두 도감 스타일
│   └── vendor/           anime.esm.min.js — CDN 대신 파일로 넣어 둔 것
└── src/
    ├── main.js           화면 전환만. 게임 로직 없음
    ├── core/             router · state(저장) · sim(실행 로그) · motion · ko(조사) · text
    ├── shell/            topbar · coursemap · debrief · codex · toolbook · report
    ├── engines/          게임 템플릿 5종 + base(공용 부품)
    ├── games/            01~17 + index.js. 파일 하나가 미니게임 하나
    └── data/             terms · terms-work · terms-extra · products · tools
```

계층 규칙은 한 방향이다. `engines/` 는 특정 미니게임을 모르고, 셸을 직접 조작하지도 않는다.
엔진은 판정 결과를 돌려주기만 하고 그리는 것은 셸이 한다.

## 미니게임 추가하는 법

**파일 하나 추가 + 목록에 한 줄.** 그게 전부다.

1. `src/games/18-내아이디.js` 를 만든다. 파일명은 `번호-아이디.js` 형식이어야 불러온다.
   기존 파일 하나를 열어 형식을 맞춘다 (`engine`, `title`, `chapter`, `data`, `debrief`, `checkedAt`).
2. `src/games/index.js` 의 `manifest` 에 한 줄 넣는다.

```js
{ id: '내아이디', no: 18, chapter: 4, engine: 'B', required: false, ready: true,
  title: '제목',  learn: '배우는 것' },
```

코스맵·상단바·결과 카드는 이 목록만 보고 그리므로 따로 고칠 곳이 없다.
엔진 코드도 건드리지 않는다. 문항·정답·해설은 전부 게임 파일 안에 있다.
이 두 곳 말고 다른 파일을 고쳐야 한다면 구조가 잘못된 것이다.

## 콘텐츠 정확성

제품 기능은 몇 달 단위로 바뀐다. 그래서 규칙을 먼저 정해 두고 콘텐츠를 넣었다.

- **확인되지 않은 정보는 넣지 않았다.** 뺀 것과 그 이유는 `TERMS.md` 부록 B에 있다
- 모든 콘텐츠에 **확인 시점(`checkedAt: '2026-08'`)** 이 붙어 있고 도감 화면에도 표시된다
- 챕터 2(도구 구분)는 **공식 문서로 전수 검증**했다. 출처 링크가 용어 카드마다 붙어 있다
- **가격·벤치마크 점수·순위는 넣지 않는다.** 몇 주면 틀린 정보가 된다.
  도구 도감은 `무료 / 부분 무료 / 유료` 정도의 거친 구분만 쓰고 "최고" 같은 표현을 쓰지 않는다
- 도구 도감은 **카테고리가 뼈대이고 도구는 예시다.** 이름은 갈려도 칸은 남게 만들었다
- 장점만 적힌 카드는 없다. 모든 도구 카드에 주의점 칸이 채워져 있다
- 도구 도감 맨 위에는 "사내 승인 확인" 경고가 스크롤해도 사라지지 않게 고정되어 있다

검증 중에 요구사항 원문과 사실이 다른 항목 4건을 찾아 고쳤다 — `TERMS.md` 맨 위 표 참고.
**2026년 말에 재확인할 것**은 `TERMS.md` 부록 C에 적어 두었다.

## 외부 요청 0건

사내망처럼 외부가 막힌 환경에서도 그대로 돌아가야 하므로, 페이지가 스스로 보내는 요청은 0건이다.

- **CDN 없음.** 웹폰트·아이콘 라이브러리·애널리틱스를 쓰지 않는다. 글꼴은 시스템 폰트만 쓴다
- 애니메이션 라이브러리(anime.js)는 `assets/vendor/` 에 파일로 들어 있다. 저장소 밖에서 받아오지 않는다
- **LLM API 호출 없음.** 판정도 "AI가 일하는 중" 실행 로그도 전부 미리 써 둔 규칙(`core/sim.js`)으로 만든다.
  API 키가 필요 없는 이유가 이것이다
- 저장소도 없다. 진행도는 그 브라우저의 localStorage 키 하나에만 남고 어디로도 전송되지 않는다
- 도감의 공식 링크는 **사용자가 눌러야** 새 탭에서 열린다. 화면을 여는 것만으로는 아무 데도 접속하지 않는다

바꾼 뒤에는 개발자도구 Network 탭에서 실제로 0건인지 세어 본다.
